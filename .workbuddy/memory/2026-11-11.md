## 登录彩蛋 + 已登录账号卡片（提交 9f68eb8，已推 origin/main）

需求：参考 github.com/jibai33/Mineradio-paused 的「点眼睛 → 输入四字暗号 → 像素字动画」流程，
做像素风彩蛋；首次登录一个、退出后重新登录一个；已登录时登录页不再显示扫码区。

### 设计决策
- 彩蛋在**登录成功后弹出**（庆祝式，可跳过），不是登录前拦截门 —— 不阻塞登录。
- 两套暗号只在服务端校验：首次「世界和平」（致敬 Mineradio 的开机愿望门）、重登「好久不见」。
  前端只拿谜面/hint/字数，错 2 次给首字、错 3 次锁前两字（渐进提示沿用参考仓库）。
- 动画用 192×108 逻辑画布 + `fillRect` 逐帧（12fps，54 帧），CSS `image-rendering: pixelated` 放大；
  文案独立成像素对话框，不放进画布（初版压住小人，已改）。配 Web Audio 方波芯片音效。
- 账号卡片数据源统一用 `/api/unified/status`，覆盖 netease / qishui / qq / xy 四个 tab；
  已登录时隐藏 `.lp-form`、停掉二维码轮询，显示头像/昵称/ID/状态/能力/退出按钮。
- 彩蛋事件由前端 `syncLoginEggEvents()` 比对登录位图 diff 上报（localStorage 存 `ew_login_map`
  防启动误弹），服务端只提供 event/check/skip/replay/status 五个接口。

## 彩蛋返工：修复久别重逢卡住 + 两套动画全屏演出

用户反馈：「久别重逢」动画不显示、输入时卡住；要求两个动画都全屏展示并做出效果。

### 根因（重要）
- `open()` 重开彩蛋时**没有清掉上一轮的 `accepted` class**。旧 CSS `.egg-entry.accepted .egg-cells{display:none}`
  会把输入格子/按钮全部隐藏 → 先播过 first 再重播 return 时看不见输入框、输不进暗号，动画自然不出现。
  puppeteer 复现时 `return OPEN` 的 `accepted` 仍为 true，即为此因。
- 旧 `onInput()` 在中文输入法组合期回写 `inp.value`，且把 reveal 的 prefix 强行拼回输入串，
  会打断候选/上屏、还删不掉前两字；`validating` 在请求无响应时不会复位；
  input 的 `stopPropagation()` 让 modal 上的 ESC 监听收不到（演出时按 ESC 无效）。

### 方案
- 重写 `egg.js` 为全屏 stage：canvas 按视口算逻辑分辨率（`U=min(CW/192,CH/108)`，
  设计坐标 192×108 等比居中，`px()` 映射并整数取整，`band()` 全宽过扫），CSS `width/height:100%` + pixelated。
- 四幕分镜（84 帧 @12fps）：静 / 起 / 潮 / 落；HUD 四段进度、幕间字幕（打字机）、
  act2 白闪+镜头抖动、落版大标题；待机循环前 18 帧作为暗号门背景。
- 视觉加厚：提亮夜空色板、斜向星云带、像素云、双层山、synthwave 透视网格地面、
  带环行星（first）/ 大光晕月亮（return）、主体放大 1.6 倍、双朵大像素烟花、光柱与星雨。
- 输入：composition 感知（组合期不回写）、reveal 只做状态栏提示不预填、
  4 个汉字自动提交 + 显式「确认」按钮/回车、同源 fetch + 6s `AbortController` 超时、
  ESC 在 input 上就地处理、错误后清空重输。`Egg.debug()` 暴露内部状态便于回归。
- `egg.css` / `index.html` 同步改为全屏结构，账号卡片样式保持不动。
