## 评论功能打通三平台（commit dd52291，**未推送：网络不通**）

- 起点：用户说「同步评论功能」。核查发现两件事都比预想严重——
  1. 评论只有网易云能用，QQ / 汽水 / 小宇宙 一律「暂不支持」；
  2. v2 布局把 `#stage` 设为 `display:none`，而 💬 在 stage 里 → **评论抽屉完全点不到**；
     加上 `openComments` 只置 `hidden=false`、从不加 `.show`，抽屉一直停在 `translateX(100%)` 屏幕外。
- QQ 评论真实接口（试出来的，写进代码注释了）：
  - 读：`https://c.y.qq.com/base/fcgi-bin/fcg_global_comment_h5.fcg`，
    `cmd=6` 热评 / `cmd=8` 最新（带 `commenttotal`），参数 `biztype=1&topid=<数字songid>&pagenum&pagesize`
  - 写：同接口 `cmd=1` + `content`，未登录回 `{"code":1000,"msg":"login check failed"}`
  - **走不通的**：musicu.fcg 的 `music.globalComment.CommentRead.CommentRead`（GetHotCommentList / GetCommentList）
    一律回 `500003 / subcode 860100005`
  - **顺手修的真 bug**：新版 QQ 搜索只回 `id`（数字），`mapQQSong` 只读 `t.songid` → 所有曲目 `songId=0`，
    评论要拿它当 topid，非修不可
- 统一层 `app/modules/comments.js`：`read()` / `write()`，平台差异（offset / 页码 / cursor）在服务端换算，
  前端只认 `nextToken` 不透明游标；小宇宙回 `unsupported` + 一句人话。
- 汽水：`handleQishuiComments` / `handleQishuiCreateComment` 模块里本来就有，只是没接 `/api/comments`。
- 前端：入口加在底部播放条 `#bar-comments` + ⌘K；跟随当前曲目（`syncCommentsToTrack`，gen 丢弃过期响应）；
  热评/最新分区、加载更多、发评论、未登录「去登录」、头像超时 5s 退 `♪` 占位。

  `/api/(song|qq/song|qishui/song)/url` 的响应伪造成一个假地址，队列就稳了。

## 每日彩蛋「今日签」（commit 4e80b57，已推送）

- 需求原话：「增加每日登录彩蛋」。判断：登录彩蛋（egg.js，输暗号 + 四幕全屏）是账号登录触发的一次性演出，
  不能复用；每天打开应用这件事需要另一层更轻的东西 → 右下角浮出的小卡。
- 服务端 `app/modules/daily-egg.js`：
  - 日期一律本地时区（`dayKey` 用 getFullYear/getMonth/getDate），不用 UTC
  - **status 只读、claim 才落盘** —— 刷新页面不会刷连续天数
  - 跨天 +1 / 断签归 1 并记 `breaks`，`best` 单独保留；断签不假装连上
  - 短句 40 条、调式 6、动作 8，全部按「距 2024-01-01 的天数」与 hash 稳定生成
  - 里程碑 3/7/14/30/60/100/180/365；`/api/daily/{status,claim,skip}`
- 前端 `daily.js` / `daily.css`：等 boot 退场再浮出、登录彩蛋开着就让路、不抢焦点；
  正面签 + 背面今日指令与里程碑进度；10 秒没人理压暗到 .62；Esc 收起。
- 关键取舍：**打开即 claim**（不要求点「收下」），否则忘了点就断签 = 惩罚用户。
- 踩到的坑：
  1. `.ds-seal` 用 `hidden` 时，`.ds-seal + .ds-x { margin-left: 8px }` 仍会命中，
     把关闭按钮的 `margin-left:auto` 覆盖掉 → 改成 `.ds-date { margin-right: auto }`
  2. 卡片入场用 `requestAnimationFrame` 加 `.is-in`，**后台标签页 rAF 被挂起** → 卡片卡在透明态；
     改用 setTimeout。测试也改成一次只留一个 page，否则同类断言会飘
  3. claim 会把 `broken` 清掉，卡片被刷新成「第 1 天」→ 服务端返回 `wasBroken`，前端再用 `brokenLock` 锁住
  4. 测试里连写状态文件会与上一页面的在途 claim 抢同一份 json（出现「连续 2 天」），
     解法：写状态前先关页面 + 等 250/450ms
- egg.js 扩展：`open()` 支持 `gate:false` 直进 cinema，新增 `drawDaily`（唱片从地平线升起，太阳在背后），
  每日场景藏掉「再看一次」；close 时恢复该按钮，避免影响登录彩蛋。
- 回归：`dist/check-daily-logic.js` 23 项、`dist/check-daily-ui.js` 33 项，连跑 5 次全绿；
  `dist/check.js` 与 `dist/check-comments.js` 基线未破。
