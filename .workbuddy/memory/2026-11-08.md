## 闻曲 Earworm macOS 版：纯像素风改造（已提交 7515301，已推送）

- 新增 `app/web/pixel.css`：纯覆盖层（不改业务样式），零圆角 + 2px 边框 + 硬投影 +
  CRT 扫描线；全站 12/24/36/48px 像素字（`app/web/fonts/ark-pixel-12.woff2`，Ark Pixel 12 GB2312 子集 215KB）。
- 开机动画：`index.html` 内联 `#boot-critical` 重做为 8-bit 分镜，总时长 3.02s
  （0.16s 徽章 → 0.66s 打字机 → 1.3s 十二格进度 → 2.48s 闪光 → 2.80s 擦除）；
  `boot.js` 的 `DURATION = 3020` 必须与 CSS 的 `bootWipe .22s 2.80s` 同步改。
- 用户明确要求「纯像素风，不要国风像素风」→ 删掉朱砂印章（顶栏/登录弹窗/开机）、
  `.bc-glyph` 巨型装饰字、`.side-panel::after` 书法水印；品牌标记改为琥珀描边的像素音符徽章
  （11×11 精灵，CSS data-URI）；红色只留给危险操作。
- 图标：`scripts/make-icons.js` 重写为像素风——应用图标复用 `app/web/icon.svg`（32×32 网格，
  11×11 音符 `<use>` 放大 32 倍），菜单栏为 11×11 纯黑 template；tray 用「8 倍出图 + sips 缩小」，
  因为 Chrome 在极小视口（≤44px）截图会得到空图。
- 迷你播放器 `electron/mini.html` 同步像素化（像素字、方块按钮、分段进度条、11×11 矩形图标）。
- 修复：`.rail-card { min-width: 0 }`（长标题的 min-content 会把卡片撑到 138/180/304px）。

## 环境坑

- `electron-builder` 打包时下载 Electron 会 504（代理不稳）。用本地副本即可离线打包：
  `npx electron-builder --mac dir -c.electronDist=node_modules/electron/dist`。
- 本沙箱 grep CLI 对部分文件返回空（疑似 locale），改用 Grep 工具。
- Electron 窗口被遮挡时 CDP 截图会拿到过期帧（开机动画帧全黑），验证动画用 headless Chrome 同尺寸截。
